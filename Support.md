# FITS QuickGuide

FITS QuickGuide is the official workflow guide and documentation app developed for FITS QuickLook X and FITS QuickLook Mobile.

As the FITS QuickLook ecosystem continues to expand with features such as 2D FITS visualization, BINTABLE analysis, distortion correction, AI-based noise detection, and multi-file Workspace workflows, the original built-in help system is no longer sufficient to fully cover all scientific workflows and operational details.

FITS QuickGuide was therefore designed as a dedicated documentation and workflow platform that provides centralized feature explanations, interface guidance, workflow tutorials, and scientific-processing references for the FITS QuickLook ecosystem.

The application is available on iPhone, iPad, and Mac, with workflow guidance adapted for different device platforms and interaction styles.

## Features

- Workflow documentation for FITS QuickLook X and Mobile
- Keystone and Smile distortion-correction guides
- AI-based noise-detection workflow explanations
- BINTABLE and Matrix visualization documentation
- Workspace and multi-file analysis guidance
- Profile, Compare, and Advanced tool references
- Scientific plotting and visualization workflows
- Built-in onboarding and Help guidance
- Multi-platform workflow support across Apple devices

## Platform Support

- iPhone
- iPad
- Mac

Built using native Apple technologies.

## Purpose

FITS QuickGuide is intended to help users understand scientific FITS workflows more efficiently, especially when working with complex astronomical datasets and advanced spectral-analysis operations.

Some workflow explanations are also based on methods described in the author's published or ongoing research workflows involving fiber spectral-image processing and distortion correction.
